Problem

BILTIQ-007–011 deliver the pipeline pieces; nothing yet ties them together or presents a public entry point. CDSCO's pipeline.py orchestrates detect→merge→pseudonymise→generalise but is coupled to a PDF extractor and an optional LLM call. This task ports the orchestration as a clean library function over text input (extraction is the caller's concern), wires the public biltiq_privacy API, and tags the first publishable release v0.1.0.

User Impact

External. First usable release: pip install biltiq-privacy, then anonymise(text, detector=..., key=..., regime=...) returns anonymised text + detections + audit row + compliance report. This is the milestone where the library becomes consumable by CDSCO, CommandCenter, and ManthanQuant.

Acceptance Criteria

  • DONEAC1 — A top-level anonymise(text, *, detector, key, generated_at, regime=None, generalise=True, prev_hash=GENESIS_PREV_HASH) -> AnonymiseResult chains Detector→Pseudonymiser→Generaliser→(Regime)→AuditChain; result carries anonymised_text, detections, audit_row, and compliance (when a regime is given). generated_at and prev_hash are caller-supplied — the library reads no clock (BILTIQ-010/011 determinism precedent, dev-ruled 2026-06-11).
  • DONEAC2 — biltiq_privacy/__init__.py exports the public surface (anonymise, PresidioDetector, Detector, Regime, DPDPRegime, error types) with a stable, documented API.
  • DONEAC3 — End-to-end integration test: raw text containing Indian PII → detected → pseudonymised → generalised → DPDP report passes → audit row verifies.
  • DONEAC4 — Default path imports no PDF/LLM/DB/FastAPI; LLM detection is opt-in only via an injected detector (Phase D). Compliance: on_prem_preferred respected.
  • DONEAC5 — Package version set to 0.1.0; CHANGELOG.md entry added; README has a runnable usage example; sdist + wheel build cleanly and v0.1.0 is published to PyPI at Ship (dev-ruled 2026-06-11 — publish in-task, not tag-only; publish itself is a dev-confirmed action with dev-supplied credentials).
  • DONEAC6 — python-core builds and imports cleanly; full test suite green; passes --strict type check + banned-vocab/residue gates.
  • DONEAC7 — Publishable packaging (dev-ruled 2026-06-11, plan-review finding #1): en-core-web-sm is removed from [project].dependencies (PyPI rejects direct-URL deps) and kept on the dev/CI install path; the built wheel's metadata contains no direct-URL Requires-Dist (gate-tested); PresidioDetector gains opt-in auto_download_model=False — when True and the model is missing, it downloads on first detect(); default path makes no network call (guard-tested); MissingNERModelError's message names both remedies; README documents the post-install line; ADR records the amendment to the 2026-05-17 "spaCy bundled" decision.

Out of Scope

  • REST sidecar (BILTIQ-013) and native SDKs (Phase E).
  • PDF/CSV extraction adapters — caller passes text (may be a thin follow-up helper).
  • LLM/hybrid detection (Phase D); extra regimes/region packs (Phase C).
