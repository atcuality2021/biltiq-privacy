What Went Well

  • Probing real Presidio output before writing the threshold assertions saved a mysterious test failure. The recognisers attach context words, so on the labelled sample_indian_pii blob the context-aware enhancer boosts IN_VOTER_ID from 0.70 to 1.0 — a 0.8-threshold test over that blob would not have dropped it. Observing the live output first, then splitting the suite (context-rich blob for "detect all 8", a purpose-built context-free string for threshold filtering) made the threshold tests deterministic. Characterization-by-observation beat assertion-by-assumption.
  • DetectedEntity as a Detection TypedDict subclass (adding only source) eliminated a parallel record type. Because a TypedDict is a runtime dict, the test fed a DetectedEntity straight into Pseudonymiser.pseudonymise_text (typed list[Detection]) and it pseudonymised the span — proving consumer-compat at runtime, not just by key-set. AP#1 defended at design and confirmed in test.

The Step-3 gate required two fixture self-checks but no artifact named a test module to hold them (a fixtures module is not test_*-collected).
