Build Sequence

Each step = one logical commit. TDD: RED → GREEN in the same step. Every code step's gate runs pytest -q + mypy --strict on the server package + full suite GREEN, with no network (TestClient only). Step 1 — Prep: py.typed marker for python-core (PEP 561) S

Rationale: Must come first: the server's [tool.mypy] strict = true imports biltiq_privacy in almost every module, and without a PEP 561 marker mypy raises import-untyped on import biltiq_privacy — so the "mypy --strict clean" gate every later step claims is unachievable until this lands. The library is already fully typed (it passes its own strict check); this only advertises that. Additive, zero-logic — also gives the v0.1.1+ native SDK type consumers a typed surface. (Caught by plan-reviewer round 1, AP#4; design § Files-to-touch updated to bring python-core under review.)

Files: packages/python-core/biltiq_privacy/py.typed (NEW — empty marker), packages/python-core/pyproject.toml (EDIT — force-include the marker in the wheel)

Tests: none new (packaging marker). Verification: mypy --strict against a one-line probe module import biltiq_privacy; biltiq_privacy.anonymise resolves with no import-untyped error; python-core own suite still GREEN.

Gate: mypy --strict resolves biltiq_privacy import (no import-untyped); python-core test suite GREEN; wheel build includes py.typed

Rationale: The security boundary, isolated as a small early commit so the mandatory human review reads a ~2-module diff, not auth logic scattered across the PR (design § Rollout step 1). Rollback Plan

Net-new package surface — python-core is touched only by an additive zero-logic py.typed marker (Step 1), so pre-publish rollback is reverting the packages/python-server/ files + the root doc edits + the one marker/packaging line. No data, no schema, no migration (stateless server — audit rows are returned, never stored). Post-publish (a later Ship): a PyPI version is immutable → yank and ship a fixed 0.1.1; never delete-and-reupload. The publish action itself runs only on explicit dev confirmation with dev-supplied credentials.

Risks

RiskStepSeverityMitigation
R1 — Auth bypass: a data route ships without the JWT dependency, or the algorithm allow-list is widened, re-opening alg-confusion 2, 5 HIGH Router-level dependencies=[Depends(require_jwt)] (not per-route); single-element algorithms=["HS256"] pinned + test_verify_token_rejects_alg_none_and_rs256; one-grep auditability; mandatory human review of Step 2 + Step 5 auth boundary.
R2 — Secret leakage: JWT secret / HMAC key / Authorization header written to a log or response 2, 4, 5 HIGH Secrets read once in load_settings(), flow only via Depends; never in any wire model; handlers log method+path+status+counts only; test_no_pii_in_response.py + the AC6 log-capture assertions pin it. README sources secrets from a manager, not a committed .env.
R3 — PII in logs: RedactionFilter is still PLANNED (stack.md), so request bodies/detection values must never be logged 4, 5 MED Handlers never log text/spans/tokens; log-capture assertion in test_no_pii_in_response.py + code-review checklist item (dev ruling: no custom ruff rule at v0.1.0). Detection spans in responses are inherent to the contract, documented, routed to access-controlled sinks.
R4 — Event-loop blocking: an async def handler calling the sync Presidio library inline stalls all in-flight requests 5 MED Detector-touching handlers are plain def → FastAPI threadpool (alt #7); cross-CPU parallelism is the --workers knob (AC8). Design § Performance pins the rationale.
R5 — Startup crash-loop: a missing NER model takes the whole service down instead of surfacing observably 4 LOW Lifespan catches MissingNERModelError → degraded start; /healthz reports 503, data endpoints 503 until restart with the model present (AC7). test_lifespan_degrades_on_missing_ner_model pins it.
R6 — Wire/library drift: a pydantic model silently diverges from its library type, shipping a wrong contract to SDK consumers 3, 7 LOW Field-name contract test (test_audit_record_and_row_models_mirror_library_keys) + OpenAPI drift gate (Step 7). Thin-shim watch: models mirror, never redefine.
