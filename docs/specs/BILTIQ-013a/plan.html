Step 1 — Mint module + tests + console-script M

Rationale: The token-signing boundary, as one reviewable commit (the mandatory human-review unit). mint.py is the single production jwt.encode caller, decomposed into build_parser() (--sub required; --ttl default 3600 via a _positive_int argparse type that rejects ≤ 0; repeatable --claim; no --secret), _parse_claims() (split on first =; reject malformed and reserved sub/iat/exp), _build_payload() (datetime.now(UTC), tz-aware iat/exp, shape identical to conftest._mint_token), _read_secret() (env-only via config._JWT_SECRET_ENV; raises module-local MintError if unset/empty), and main(argv) -> int doing the single jwt.encode(payload, secret, algorithm=_MINT_ALGORITHM), writing only the token to stdout via sys.stdout.write(token + "\n") and all diagnostics to stderr (exit code from the return). _MINT_ALGORITHM = "HS256" is module-local; an equality test pins it to auth._ALGORITHMS[0] (dev decision: own constant + test, not a runtime auth import — keeps the CLI's import graph to argparse+pyjwt+config). The AC6 verify-only invariant ships in this commit too, so the module arrives with its own structural proof.

Files: biltiq_privacy_server/mint.py (NEW), tests/test_mint.py (NEW — AC1–AC5 + the _MINT_ALGORITHM equality test), tests/test_mint_invariant.py (NEW — AC6: import-graph reachability + jwt.encode source-grep), pyproject.toml (EDIT — [project.scripts] biltiq-privacy-mint = "biltiq_privacy_server.mint:main"; version stays 0.1.0; coverage config already present from BILTIQ-013)

Tests (≈13):
  • AC1 — minted token round-trips: verify_token(mint_main_output, secret=…) returns claims with sub == "ops"; stdout is the token and nothing else (no banner/log).
  • AC2 — build_parser() exposes no --secret/--key action (introspect parser._actions option strings); secret never in stdout.
  • AC3 — unset and empty BILTIQ_JWT_SECRET → non-zero exit, message on stderr naming the env var, no secret value echoed, stdout empty.
  • AC4 — iat/exp tz-aware UTC; exp - iat == ttl; default ttl 3600; --ttl 0 / --ttl -5 rejected (non-zero, stderr).
  • AC5 — --claim a=1 --claim b=2 merged as string values; --claim nope (no =) rejected; --claim sub=x/iat=…/exp=… rejected as reserved.
  • Drift — mint._MINT_ALGORITHM == auth._ALGORITHMS[0].

Gate: pytest tests/test_mint.py tests/test_mint_invariant.py -q GREEN; mypy --strict clean (no Any, no unjustified type: ignore); ruff check clean (DTZ-clean via tz-aware datetimes); full suite GREEN; coverage ≥90% on mint.py. This commit is the mandatory human-review unit.
