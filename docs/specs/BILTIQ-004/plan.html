Step 4 — AC4 error-path tests (AgeProcessError, RED→GREEN) S

Rationale: AC4 demands that non-zero exit from the age subprocess raises AgeProcessError at __exit__ with stderr captured. Two failure modes to assert: (a) invalid recipient string (age refuses to encrypt to a malformed recipient); (b) corrupted ciphertext (one byte flipped past the header — age refuses to decrypt).

Files: packages/python-core/tests/backup/test_age_stream.py (UPDATE — add 2 error-path tests).

Tests:

  • test_corrupted_ciphertext_raises_age_process_error — round-trip encrypt, flip one byte past the age header offset (e.g. byte 256), assert AgeProcessError on read; assert isinstance + stderr capture (AC4)

Without this, a future regression that breaks the skipif gate would silently mark the whole suite as skipped and CI would stay green falsely.

Step 7 — scripts/install-age.sh POSIX autodetect installer L

Rationale: The largest single artifact in the plan (~250 LOC POSIX sh). All autodetect paths in one step to keep the script's control flow reviewable as a whole. Style mirrors scripts/install-curator-hook.sh (BILTIQ-003) — POSIX sh, set -u, explicit arg parser, -h/--help emits a header slice via sed -n. Sentinel-file mechanism (per Q3 confirmation) at $HOME/.local/share/biltiq-privacy/age-installed-by-script.

Files: scripts/install-age.sh (CREATE — see design § Files to Touch for function breakdown).

Function topology (per design):

  • _help() — emits the script header slice via sed -n '2,N p' "$0"; matches install-curator-hook.sh idiom.
  • _detect_os() — uname -s case branch returning linux | macos | windows-shell | unknown.
  • _verify_age_version() — parses age --version; refuses to overwrite an existing ≥ 1.2.0 unless --force.
  • _install_linux() — autodetect order apt-get → dnf → pacman → snap → tarball; falls through cleanly between branches.
  • _install_macos() — Homebrew → tarball.
  • _install_windows_shell() — emits scoop / choco directive; exit 2.
  • _install_tarball() — fetches FiloSottile/age release for AGE_VERSION="1.2.0", verifies SHA256 against committed-in-script baseline, places binary at $HOME/.local/bin/age, writes sentinel.
  • _uninstall() — reads sentinel; removes only the listed binary + sentinel; refuses if no sentinel exists.
Tests:
  • shellcheck scripts/install-age.sh — clean (CI gate; catches shell-quoting/syntax errors on all branches regardless of OS).
  • Smoke: bash scripts/install-age.sh --help — exit 0, prints header slice.
  • Smoke: bash scripts/install-age.sh -h — exit 0, identical output.
  • Smoke: bash scripts/install-age.sh --unknown-flag — exit 2 with usage error.
  • Dry-run (Linux dev machine): BILTIQ_AGE_DRY_RUN=1 bash scripts/install-age.sh — prints what would be installed without executing the package manager. (Note: dry-run env var should be implemented in this step.)
  • Manual: bash scripts/install-age.sh --uninstall on a Linux machine without the sentinel → exit 2 with "no script-installed age binary; refusing to uninstall".

Gate: all smoke runs above pass; shellcheck clean.

Rollback Plan

Pure additive change — no schema state, no data migrations, no external service contracts to unwind, no in-flight consumers (the v0.5.0+ backup orchestrator that will be the first internal consumer hasn't shipped). Rollback is git revert <merge-sha>. The only residue revert leaves behind is the operator's locally-installed age binary — harmless and remains useful for non-biltiq-privacy purposes. scripts/install-age.sh --uninstall remains the documented removal path even after revert (the script is in git history regardless). No feature flag, no toggleable behavior, no consumer to drain.

Risks (plan-specific; design Risks #1–6 apply at design-level)

RiskStepSeverityMitigation
Step 7 install-script ~250 LOC overflows the ≤1 hour atomic-step budget on a cold start. The L band (165 min midpoint) accommodates it, but a junior dev encountering POSIX sh quoting edge cases for the first time could blow past 3 hours. The script's branch density (4 Linux package managers + tarball fallback + macOS Homebrew + tarball fallback + Windows directive + sentinel + flags) makes "one logical commit" defensible but tight. 7 MED Pre-write the function topology (already in step 7 above) so the dev fills in function bodies rather than designing on the fly. Reference scripts/install-curator-hook.sh as the in-repo idiom source. If the step bleeds past 2 hours wall-clock, split at the OS-path boundary: step 7a Linux only, step 7b macOS + Windows-shell + tarball. Plan-reviewer may flag this as a "single-step-too-large" warning; the dev decides to pre-split or accept the L band.
SHA256 baseline for the install-script tarball path requires fetching upstream artifacts at write-time — the script commits the SHA256 of each (OS × arch) tarball, which means the dev needs network access to github.com/FiloSottile/age/releases/v1.2.0 at step 7 to compute the baselines. 7 LOW Repo dev machine has network access (git push origin feature/biltiq-004-age-wrapper requires it). Pinned to AGE_VERSION="1.2.0" per design; release artifacts are immutable on GitHub releases. If the upstream tags are rotated (rare), the SHA256-mismatch behaviour exits 1 with the manual-install runbook reference.
Step 2 ships ~80 LOC of new Python in a single commit — slightly above the typical "60 LOC per atomic step" heuristic. The wrapper module is the project's first subprocess.Popen + @contextmanager + BaseException cleanup pattern; review density is higher than typical. 2 LOW Design § Approach narrates the exception-flow shape in three paragraphs; review eyes already have the source-of-truth context. The CDSCO-RegAI prior-art (scripts/_backup_lib/age_stream.py) is the line-by-line porting target — the dev cross-references during code-review. Split into 2a (exception classes + helper) + 2b (context managers) only if step 2 mid-flight feels too dense.
AC6 positive-control test (step 5) is conceptually subtle — a test that proves "the skip mechanism runs" can be misread as "trivial happy-path assertion that age is installed". A future reviewer might delete it as redundant. 5 LOW The test's docstring (added in step 5) explicitly names the regression class it guards against: "Without this test, a future regression that breaks the skipif gate would silently mark the whole suite as skipped and CI would stay green falsely. This test verifies the skip wiring; removing it removes the in-CI gate that the wiring works." Code-reviewer skill should preserve this comment if a future PR proposes test deletion.
