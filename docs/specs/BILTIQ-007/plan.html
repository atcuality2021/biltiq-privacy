Step 2 — core/doc_hasher.py + hmac_key fixtureM

Rationale: Stateless hashing has no in-task deps; the Pseudonymiser (Step 3) consumes hmac_pseudonymise. Adds the shared hmac_key fixture that 011/012 will reuse. Est. ~45 min.

Files: CREATE biltiq_privacy/core/doc_hasher.py (hash_document, hash_text, hmac_pseudonymise(value, *, key: bytes|str)); CREATE tests/conftest.py (deterministic 32-byte hmac_key fixture per stack.md); CREATE tests/core/test_doc_hasher.py.

Tests:
  • test_hash_text_is_sha256_hex / test_hash_document_bytes — known input → known SHA-256 digest (AC1).
  • test_hmac_deterministic — same (value, key) → same digest across calls (AC3).
  • test_hmac_key_sensitivity — different key → different digest (AC3).
  • test_str_and_bytes_key_equivalent — "k" and b"k" yield identical output (locked str-convenience).
  • test_no_settings_import — module source contains no settings/os.environ read (AC1, static assert).

Gate: pytest packages/python-core/tests/core/test_doc_hasher.py — GREEN.

Step 3 — core/pseudonymiser.py (Pseudonymiser class)M

Rationale: The task's core deliverable; depends on Steps 1 (exception) and 2 (hasher). Est. ~50 min.

Files: CREATE biltiq_privacy/core/pseudonymiser.py (Detection/AuditRecord TypedDicts; Pseudonymiser.__init__(*, key), make_token(entity_type, value, *, token_length=8), pseudonymise_text(text, detections)); CREATE tests/core/test_pseudonymiser.py.

Tests:
  • test_make_token_format — token matches [TYPE_<8 hex>] at default (AC2, characterization).
  • test_token_length_configurable — token_length=12 → 12 hex chars (AC2).
  • test_token_deterministic_per_key — same value+key → same token; different key → different (AC3).
  • test_pseudonymise_text_multi_entity — multiple detections replaced; end→start order keeps offsets valid; audit list has the 5 CDSCO keys in restored order (AC2, AC5).
  • test_empty_key_raises — Pseudonymiser(key=b"") / missing → HMACKeyRequiredError at construction, before any text (AC4).

Gate: pytest packages/python-core/tests/core/ — GREEN; mypy --strict clean.
