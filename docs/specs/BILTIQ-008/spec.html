Problem

The pipeline needs an irreversible generalisation step after pseudonymisation — coarsening quasi-identifiers (exact age → bracket, exact date → month/year, precise location → region) so re-identification by linkage is harder. CDSCO has this as backend/modules/anonymisation/generaliser.py (112 LOC, pure regex + string ops, no coupling). It is India-centric (region maps, Aadhaar / PAN / phone patterns). Port it into core/generaliser.py, keeping the Indian rules as the default while leaving room for region packs to extend it.

User Impact

Internal/infra. Adds the generalisation stage so anonymised output is not just token-substituted but also coarsened — the difference between pseudonymisation and a genuine privacy posture. Feeds BILTIQ-011 (DPDP generalisation-irreversibility check).

Acceptance Criteria

  • DONEAC1 — Six generaliser functions ported with CDSCO behaviour preserved verbatim: generalise_age(age: int) -> str (20-year brackets), generalise_date(date_str: str) -> str ("Month Year"), generalise_location(location: str, *, region_map=None) -> str (region rollup), generalise_phone(phone: str) -> str, generalise_aadhaar(aadhaar: str) -> str, and generalise_pan(pan: str) -> str (suffix/middle masking). The _GENERALISER entity-type dispatch table is preserved intact.
  • DONEAC2 — generalise_text(pseudonymised_text: str, spans: list[GeneralisationSpan], *, region_map=None) -> str applies the per-entity generalisers across detected spans via the dispatch table. GeneralisationSpan is a TypedDict {entity_type, text, pseudonym_token} that the BILTIQ-012 orchestrator assembles from BILTIQ-007's Detection + AuditRecord — no edit to the shipped BILTIQ-007 types.
  • DONEAC3 — Module is pure: stdlib + re only; no config/DB/FastAPI/LLM imports.
  • DONEAC4 — Indian region/ID rules are the documented default; generalise_location and generalise_text accept an optional keyword region_map (defaulting to the bundled Indian state→region table) so a future region pack supplies its own rollups without editing core (inject-with-default seam; full region-pack loader deferred to Phase C).
  • DONEAC5 — Docstring + docs state explicitly: this is rule-based generalisation, NOT a dataset-level k-anonymity guarantee (measurement is BILTIQ-021). No overclaiming.
  • DONEAC6 — Characterization tests cover each generaliser + irreversibility (output cannot recover the exact input). Passes --strict.

Out of Scope

  • Dataset-level k-anonymity / l-diversity / t-closeness measurement (BILTIQ-021).
  • EU/US/UK generalisation rules (region packs, Phase C).
  • Detection and pseudonymisation (BILTIQ-009 / 007).
