Step 1 — core/audit_chain.py: pure hash chain + full test suiteM

Rationale: The whole feature is one cohesive leaf module — the two free functions plus the genesis constant and two TypedDicts — with no consumer yet, so it lands as a single TDD commit (RED suite → GREEN). Depends only on the shipped doc_hasher.hash_text. Covers AC1–AC5 in code + tests. Est. ~50 min (within the 1-hour atomic bound; ~50 LOC module + ~11 focused test cases).

Files: CREATE packages/python-core/biltiq_privacy/core/audit_chain.py — SPDX header + CDSCO-origin docstring noting the SQLAlchemy coupling was dropped (AC3); from __future__ import annotations; import json; from typing import Final, TypeAlias, TypedDict; from biltiq_privacy.core.doc_hasher import hash_text. Defines JsonValue: TypeAlias = str | int | float | bool | None | list["JsonValue"] | dict[str, "JsonValue"] (the TypeAlias form, NOT the PEP 695 type X = ... statement — the latter is 3.12+ grammar and the floor is requires-python >=3.11; keeps payload typed without Any); GENESIS_PREV_HASH: Final[str] = "0" * 64; class ChainedRow(TypedDict){prev_hash, payload, hash}; class VerifyReport(TypedDict){valid, first_broken_index}; private _canonical_json(payload) -> str = the exact json.dumps(payload, sort_keys=True, separators=(",", ":"), ensure_ascii=False) call; append_row(prev_hash, payload) -> ChainedRow computing hash = hash_text(prev_hash + _canonical_json(payload)); verify_chain(rows) -> VerifyReport walking once, recomputing each digest + checking links (row 0's prev_hash == GENESIS_PREV_HASH; later rows' prev_hash == prior row's hash), reporting the first failing index, never raising on tamper. No SQLAlchemy/DB/session/FastAPI/LLM import (AC3). CREATE packages/python-core/tests/core/test_audit_chain.py (cases below; tests/core/__init__.py already exists).

Tests (AC1, AC2, AC3, AC4, AC5):
  • test_append_row_commits_to_prev_and_payload — append_row(GENESIS_PREV_HASH, payload) returns a 3-key ChainedRow whose hash equals hash_text(GENESIS_PREV_HASH + canonical_json(payload)) recomputed independently (AC1 success path); prev_hash and payload are stored verbatim.
  • test_multi_row_chain_verifies_valid — build a 3+ row chain by threading each row's hash into the next append_row; verify_chain returns {valid: True, first_broken_index: None} (AC2/AC5 success path).
  • test_mutated_middle_payload_detected_at_index — flip a field in the middle row's payload; verify_chain returns {valid: False, first_broken_index: i} at that exact row (AC2 tamper-evidence, AC5).
  • test_mutated_hash_detected — corrupt a row's stored hash; detected at that index (AC2 — the stored-hash recompute path, distinct from the payload path).
  • test_reordered_or_deleted_row_detected_via_link — delete/reorder a middle row; the broken prev_hash link is reported at the first offending index (AC2 link check).
  • test_bad_genesis_detected_at_index_0 — a single row whose prev_hash is not GENESIS_PREV_HASH reports first_broken_index: 0 (genesis-link failure path).
  • test_empty_chain_is_vacuously_valid — verify_chain([]) returns {valid: True, first_broken_index: None} (AC5 edge case — no raise).
  • test_single_valid_row_verifies — one append_row(GENESIS_PREV_HASH, ...) row verifies valid (AC5 edge case).
  • test_canonical_json_key_order_determinism — two payloads with the same items inserted in different key order produce an identical row hash (AC4 — sort_keys=True contract).
  • test_golden_vector_pins_cross_language_recipe — append_row(GENESIS_PREV_HASH, {fixed synthetic payload})["hash"] equals a committed expected hex digest (computed once at Build); the cross-language reproduction anchor each native SDK must match (AC4). Synthetic data only.
  • test_append_row_rejects_non_serialisable_payload — a payload with a non-JSON value (e.g. a set) makes append_row raise the stdlib TypeError from json.dumps — the validation/failure path; no bespoke exception (AC1 contract boundary).

Gate: .venv/bin/python -m pytest packages/python-core/tests/core/test_audit_chain.py — GREEN; mypy --strict clean (no Any, no type: ignore); ruff check clean.
